## File Rules

- Store the prose manuscript as `chapter.md` inside each matching chapter folder.
- Keep page prompt Markdown files in the same chapter folder as the prose manuscript.
- Reusable front/back KISAH support pages live in `../../Covers/` from this arc folder.
- Interior comic pages use colored flat 2D human-drawn modern supernatural romance manga/manhwa pages. ChatGPT outputs PNG first, then approved images are manually converted to WebP as `1.png` -> `1.webp`, `2.png` -> `2.webp`, etc.
- Page prompt Markdown files remain `page-001-chatgpt-image-prompt.md`, `page-002-chatgpt-image-prompt.md`, etc.
- Do not create chapter Markdown files at the story root.
- Do not create bare chapter-number folders directly under `Comics/`.
