## Regeneration Status Rule

Existing PNGs created before the character-card standard are legacy/provisional until regenerated and approved from the updated prompts. Regenerate into the SAME canonical filenames so production-strip attachment paths do not change.

**Nari is a design revision, not merely a new angle sheet:** her old short-hair PNG is obsolete. Her new canonical must use long dark-plum hair and the more feminine adult design in the updated prompt.

Keep the visual style 100% flat 2D human-drawn manhwa: matte cel color, clean ink, controlled hard-edged shade, no glossy/cinematic/photoreal/3D treatment.
