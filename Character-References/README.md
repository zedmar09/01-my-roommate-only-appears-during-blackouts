## Generation / Storage Rule

Image-generation prompts may still request a PNG as the first local generation output. That PNG is an intermediate generation/QA file only.

After approval:
1. manually convert the approved PNG to WebP
2. store only the approved `.webp` authority in GitHub
3. use the exact `.webp` repository filename in production-strip attachment lists

Do not silently rename the canonical WebP after strips begin using it.
