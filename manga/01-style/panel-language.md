# Panel Language

Panels can change scale and shape according to narrative function.

## Common Uses

- **wide establishing panel** — location, geography, crowd, time, atmosphere
- **medium character panel** — dialogue, physical interaction, staging
- **close-up** — emotion, realization, tension
- **extreme close-up / cut-in** — eye, hand, switch, phone, key, evidence, object detail
- **narrow vertical panel** — interruption, movement, entrance, suspense
- **small reaction panel** — comedy, surprise, hesitation, silent response
- **dominant panel** — reveal, emotional peak, action impact, new information
- **borderless image** — rare memory, dream, atmosphere, or overwhelming moment

Do not make every panel equally sized. Do not automatically show every action as a separate panel if one stronger composition communicates it better.

Background detail should follow narrative importance, not a fixed rendering quota.
