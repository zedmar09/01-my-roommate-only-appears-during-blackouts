# Manga Environment References

Store reusable black-and-white manga environment references here.

Environment sheets should translate existing canonical locations into stable manga line-art geometry rather than redesign them. Recommended coverage:

- floor plan / spatial relationship sheet
- wide establishing view
- reverse wide view
- key doorway and threshold relationships
- recurring camera-angle atlas
- furniture/appliance placement
- window, wall, hallway, and room-depth relationships
- black/white fill, screentone, texture, and hatching rules

Camera angle may change; canonical geometry must not. Do not mirror layouts, add luxury features, enlarge rooms, invent doors/windows, or silently change furniture counts.
