# Character References

Each recurring character should eventually receive a compact manga master pack, for example:

```text
characters/
  nari/
    canon.md
    master-sheet.png
    chapter-variants/
```

## Master Sheet Goal

One approved black-and-white atlas should cover, where useful:

- front / 3-4 / profile / back identity
- full-body proportion
- key face angles
- core expressions
- hair construction
- signature clothing/prop details
- height/proportion relationship to other core cast

Do not reuse retired full-color Manhwa WebPs as manga authority.
