# Approved WebP Visual Authorities

This folder is the centralized location for reusable approved WebP visual authorities.

## Format Rule

- generation normally produces a PNG review candidate first
- visually review the candidate
- convert the exact accepted image to WebP
- only the approved WebP becomes reusable authority

Do not store review PNGs here.

## Current Approved Visuals

- `series-manga-style-reference-a.webp` — reference-development style asset A
- `series-manga-style-reference-b.webp` — reference-development style asset B
- `nari-canonical.webp` — **Yoon Nari exact face/hair identity authority**
- `nari-apartment-master-atlas.webp` — apartment/common-route geometry authority
- `nari-workplace-master-atlas.webp` — publishing-workplace geometry authority

## Nari Canonical Note

`nari-canonical.webp` is intentionally a tight identity crop derived directly from the approved female reference.

It exists to preserve:

- exact face structure
- almond-shaped eyes
- strong brow shape
- nose/lips/jaw read
- shaggy short-to-medium layered hair silhouette
- age read
- **no beauty mark/mole/facial dot**

It is **not** a wardrobe/environment/style authority.

Do not copy its incidental headphones, techwear, neon/cyberpunk background, lighting, or source color palette into story pages.

Do not soften or genericize Nari when using this asset.

## Story-Page Attachment Rule

Approved does not mean automatically attached.

For Chapter 001 final pages, Style A/B are **not default attachments**.

Character/environment WebPs are attached only when they control something visible on the requested page.

Page-local layout references, when explicitly used for troubleshooting, stay under `manga/04-production/` and do not belong here.

See:

`manga/02-references/generation-attachment-map.md`

for exact current attachment sets.
