# Manga Character References

Store canonical black-and-white manga reference sheets here.

Each recurring character reference should preserve the existing story/manhwa canon while translating it into manga line art. Recommended sheet coverage:

- front, 3/4, profile, and back views
- full body and head/face close-up
- neutral expression plus key recurring expressions
- hairstyle construction and silhouette
- canonical outfit construction
- glasses/accessories where applicable
- height/proportion comparison notes
- black/white fill, screentone, and hatching rules

Do not redesign characters merely to fit manga styling. Identity, age, proportions, hairstyle, clothing construction, and recurring accessories must remain canon-consistent.
