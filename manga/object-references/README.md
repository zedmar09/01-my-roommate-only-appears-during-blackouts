# Manga Object References

Store canonical black-and-white manga reference sheets for recurring props and objects here.

Recommended reference coverage:

- front / side / rear / 3/4 views where useful
- world-scale comparison against a hand or nearby furniture
- construction details that must remain stable
- cable, plug, handle, hinge, button, label, seam, and hardware placement where canonically relevant
- black/white fill, screentone, and hatching rules

Objects must retain the same identity, proportions, functional parts, and recurring placement established by existing canon. Do not simplify away story-critical hardware or add decorative details that are not canonical.
