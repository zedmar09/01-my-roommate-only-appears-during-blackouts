The page map converts the approved scene sequence into manga rhythm.

For each page record:

- page number
- page purpose
- event thread / scene
- approximate panel count (not a fixed template)
- dominant panel or composition intention
- dialogue density
- page-turn setup/payoff
- continuity exit state

Panel count and panel dimensions may change drastically from page to page. The physical page canvas remains consistent after the project page specification is approved.
