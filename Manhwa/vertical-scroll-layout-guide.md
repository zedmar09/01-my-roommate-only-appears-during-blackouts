# Vertical Scroll Layout Guide

## One Chapter, One Scroll

Finished chapter is one centered continuous vertical reader. Technical strips are invisible production chunks only.

## Width Lock

Use one fixed generation width for every technical strip. Do not independently resize before stitching. Stitch approved strips first, then uniformly resize completed master.

## Canonical Environment Anchor — Absolute

Every camera view must be physically possible inside approved environment canon. Preserve room relationships, routes, reverse-angle truth, furniture/appliances, doors/windows, wall sockets/outlets, recurring-landmark distances, hinge/handle/track mechanics and world-space scale.
Never mirror/relocate architecture/appliances/outlets for composition. Recompose camera instead.

## Local Outlet Continuity — Canon-Subordinate

Canonical visible outlet → exact. If omitted, derive only smallest plausible chapter-local detail inside existing canonical geometry. Never add/move architecture. Preserve compatible chapter continuity; canonical always wins.

## Read Beats Are Not Reader Labels

V-beat IDs and all temp-state names are planning only. Never render V/P/strip/panel/scene/shot/QA/temp-state headings, especially top-left.

## Adjacent-Slice Micro-Continuity — Absolute

New slice = new camera/read beat, **not reset**.
Preserve all unmodified state including body position/facing/feet/distance, anatomical side, worn accessories, object count/location/orientation/scale/depth/support, food/props, cords/plugs/socket/slack, chair/candle/cabinet state, power/device state, camera-axis geography, and lighting-source direction.
Occlusion is not disappearance or relocation.

## Temporary Anatomical-Side Continuity — Absolute When Used

Preserve same physical side for KNIFE HAND, PHONE HAND, WRITING HAND, SCRUNCHIE WRIST, STEP FOOT, CANDLE FOOT, BAG SHOULDER, UMBRELLA HAND, PHONE POCKET, specific earbud ear, etc. Screen-left/right may flip; anatomical side may not.

## Worn-Accessory Continuity — Absolute

Established worn items stay same body location unless visibly moved. Partial occlusion okay; disappearance/duplication/side swap/clipping/floating is not.

## Orientation / Hinge / Handle / Track Continuity — Absolute

Reverse camera may flip the image but not story-world mechanics. Preserve door/cabinet/elevator mechanisms, binder spine/rings/page-turn side, knife/sheath orientation, appliance cord origin, pot handle/cloth side, and chair front/back/pushed angle. If a view makes the correct mechanism awkward, change camera—not the mechanism.

## Object Scale / Fit Continuity — Absolute

World-space size is continuity. Do not secretly resize objects to make layout fit. Speaker/stockpot/lid/towels must fit cabinet; emergency-tray tools fit tray; A5 notebook keeps true footprint; pot/chair/table/phone/tablet/key/candle/packets/TV retain scale. Close-ups magnify on page only.

## Camera Axis / Eyeline Continuity — Absolute

Same uninterrupted conversation/action preserves world-space sides and gaze targets.
- reverse shot may flip screen-left/right but may not exchange physical sides
- characters look toward the actual speaker/device/sound/object
- crossing the 180° axis requires a neutral reorientation view first
- a tight close-up cannot be used to hide an eyeline that contradicts the floor plan

## Perspective / Lens Integrity — Absolute

Use ordinary human-eye/manhwa perspective.
Reject:
- fisheye/ultra-wide curvature of canonical straight architecture
- forced perspective that changes body/object world proportions
- extreme foreground scaling that makes connected hand/plug/knife/phone/body geometry impossible
- perspective that fakes contact or compresses route/step distance
- oblique framing that makes floor support, wall-socket mounting, threshold crossing, chair seating, or object orientation ambiguous

Drama comes from shot size, framing and vertical pacing—not lens warping.

## Mobile-Scale Evidence Legibility — Absolute

Continuity-critical proof must be understandable at normal phone reading size.
The following cannot be technically present but microscopic/ambiguous:
- wall plug + wall socket + loose plug + connected appliance cord
- key transfer
- binder page edge/rings/Section16→18 proof
- tool return
- food/chopstick path
- foot→packet contact
- chair sit/push/stand mechanics
- mask hardware movement
- knife release/fall/impact
- wrist grip/release
- phone/notebook placement
- cabinet/lid/towel/speaker reveal
- notebook handwriting and final TV message

If a wide is insufficient, use an immediately adjacent SAME-OBJECT detail with enough context. Never enlarge the world-space object.

## Crop / Gutter / Divider Safe Margin — Absolute

Continuity-critical proof must have compact breathing room from image edges.
- do not place decisive hand/foot/plug/socket/cord/knife/packet/chair leg/mask/wrist/page edge/spine/cabinet hinge/notebook/text carrier exactly on a canvas crop, gutter, diagonal divider or seam
- a diagonal divider may never cut through a critical mechanism or evidence path
- an A/E technical seam may not amputate a state-changing action unless the art is truly continuous after stitching and the mechanism remains readable
- single-pixel edge inclusion does not count as proof

## Depth-Order / Contact Continuity — Absolute

Flat overlap does not automatically prove physical relationship. Fingers actually grip/wrap, feet share floor plane with packet, hips align seat, hand contacts mask/door/cabinet hardware, blocking character occupies real floor-plan position, elevator entry crosses threshold. Foreground close-up cannot hide silent relocation.

## Critical Object / Limb Ownership — Absolute

Close-ups retain enough context to prove ownership/orientation:
- hand belongs to the same arm/anatomical side
- foot belongs to the same leg/body state
- loose plug remains connected by enough visible/contextual cord to the same appliance
- knife impact retains identifiable same-knife contour
- notebook page retains enough notebook/spine context

Do not crop so tightly that the reader cannot identify the continuing body/object.

## Flexible Object / Gravity / No-Clipping — Absolute

Cords, plugs, towels, cloth, straps, hair, paper, packets and falling objects obey support/gravity/collision. Reject floating plugs, cord-through-solid, changing cord length/slack, cloth through solid volume, falling props through bodies/furniture, or unsupported surface props.

## Lighting Source / Shadow Direction Continuity — Absolute

Within one unchanged lighting state, preserve the real light-source direction.
- powered Unit uses approved powered baseline
- blackout has no invented powered/cinematic light
- candle provides only local warm light while lit
- after candle-out, candle-derived highlights/shadows disappear
- fridge/TV/speaker pixels are not room lights unless explicitly scripted
- power return changes lighting at that event, then keeps one powered baseline
- one flicker may briefly vary the real light and returns to the same direction
- flat graphic shape separation is not a second story-world light source

Reject arbitrary shadow/highlight side swaps between adjacent same-state shots.

## Reflection / Shadow False-Duplicate Ban — Absolute

Unless scripted, no readable reflected duplicate people/objects, unknown human silhouette, shadow-person, afterimage, or human-shaped shadow from a nonexistent source.

## Physical Text Plane / Mobile Readability — Absolute

Device text stays inside the actual screen/display plane and follows carrier perspective/boundaries. Binder/note/notebook text stays on the actual page/object plane.
Story-critical exact wording must remain legible at intended mobile size; hostile distortion may affect edges but may not destroy the words. Use SAME-OBJECT details rather than enlarging the carrier in world space.

## Prop Topology / Relative Placement — Absolute

Preserve physical relative positions, scale, orientation and depth—not just count. Pot/trivet/handle/cloth/candle/chopsticks/packet/wrapper/chairs/knife/lid/towels/speaker/notebook zone and STORAGE POT vs NOODLE POT relationships remain fixed until visible movement.

## Same-Object Wide / Close-Up Semantics — Absolute

Close-up/inset is normally SAME physical object/person, not another copy. Same-moment states must agree; action progression advances once. Use dividers/reading order so representational detail cannot be read as duplicate physical object/body.

## Mandatory Mechanism Visibility — Absolute

Layout may not hide decisive mechanism for prettier reaction. Show contact/source for plug/socket, key, blade/sheath, knife fall, chair sit/stand, cabinet handle/hinge, candle, bag/tablet, packet, pen/notebook, mask hardware, wrist grip/release, door/elevator threshold.

## Character ↔ Environment Interaction — Absolute

Every slice physically believable: real body support, actual chair seating, reachable target, truthful eyeline, hinge/track motion, collision-free route, evidence clearance, stable scale, truthful depth order, canonical perspective.

## Hand Occupancy / Support — Absolute

Account for two hands and real body/surface support. Close-up cannot imply ownership/support impossible in wide.

## Deterministic Body / Object Progression — Absolute

Show continuity-critical transition: crouch→stand, closed notebook→open, pocket→hand→pocket, object hand→surface→release, old foot mark→single step→new mark, held wrist→open fingers→air gap.

## Top-to-Bottom Reader Order — Absolute

The vertical scroll must read in the exact scripted causal sequence.
- later dialogue cannot visually precede earlier dialogue
- SFX is placed at the action moment, not before its cause or after a changed result when that changes meaning
- device text cannot read before the device activates
- narration cannot interrupt/reorder action/dialogue
- side-by-side views need one unmistakable order

If one composition cannot preserve the order, use more vertical space or unlabeled sub-slices; never rewrite the script to solve layout.

## Black Read-Slice Grammar — Absolute

Every distinct vertical slice gets small black gutter; side-by-side views use diagonal/slanted black divider. Suspense/time cuts may use slightly stronger compact gap. Never giant filler band. A/E technical seam remains invisible when art continues. Critical proof gets safe margin from gutters/dividers.

## Narration Placement / Scenario Integration — Absolute

Narration treatment/placement follows scenario, not one top-left box. Never cover action/evidence or disrupt causal reading order.

## Lettering / SFX Evidence Safety — Absolute

Never let text cover/sever contact, hinge/track, scale/fit, depth proof, plug/cord, key, knife, chair, mask/wrist, candle, food path, packet, phone/notebook placement, device clues, gaze targets, light-source proof, or mobile context. Reflow text/camera instead.

## No Dead Bottom Canvas — Absolute

No huge empty black/white areas unless real story function. Never invent filler.

## Reader Background / Power State

Powered scenes neutral baseline. Outage deep charcoal/black field with readable separation and no invented light. Restore normal baseline after Unit power return.

## No Traditional / Technical Page Artifacts — Automatic Reject

No page numbers, V/P/strip/beat/panel/scene/shot IDs, temp-state labels, crop guides, QA notes, technical headers/footers.

## Text Safety

Never split reader-facing text or decisive action proof across seams/dividers in a way that breaks readability/order.
