# Vertical Scroll Layout Guide

## One Chapter, One Scroll

Finished chapter is one centered continuous vertical reader. Technical strips are invisible production chunks only.

## Width Lock

Use one fixed generation width for every technical strip. Do not independently resize before stitching. Stitch approved strips first, then uniformly resize completed master.

## Canonical Environment Anchor — Absolute

Every camera view must be physically possible inside approved environment canon. Preserve room relationships, routes, reverse-angle truth, furniture/appliances, doors/windows, wall sockets/outlets, recurring-landmark distances, hinge/handle/track mechanics and world-space scale.
Never mirror/relocate architecture/appliances/outlets for composition. Recompose camera instead.

## Local Outlet Continuity — Canon-Subordinate

Canonical visible outlet → exact. If omitted, derive only smallest plausible chapter-local detail inside existing canonical geometry. Never add/move architecture. Preserve compatible chapter continuity; canonical always wins.

## Read Beats Are Not Reader Labels

V-beat IDs and all temp-state names are planning only. Never render V/P/strip/panel/scene/shot/QA/temp-state headings, especially top-left.

## Adjacent-Slice Micro-Continuity — Absolute

New slice = new camera/read beat, **not reset**.
Preserve all unmodified state including:
- body position/facing/feet/distance/seated-standing
- anatomical hand/foot/wrist/shoulder/pocket identity
- worn accessories
- object count/location/orientation/scale/depth/support
- food/noodle/chopstick/packet/wrapper
- knife/sheath/floor impact orientation
- key/manual/note/pen/notebook/phone/tablet/bag
- cords/plugs/socket/slack
- chair position/angle
- candle/holder
- cabinet/stockpot/lid/towels/speaker
- power/device state

Occlusion is not disappearance or relocation.

## Temporary Anatomical-Side Continuity — Absolute When Used

Preserve same physical side for KNIFE HAND, PHONE HAND, WRITING HAND, SCRUNCHIE WRIST, STEP FOOT, CANDLE FOOT, BAG SHOULDER, UMBRELLA HAND, PHONE POCKET, specific earbud ear, etc. Screen-left/right may flip; anatomical side may not.

## Worn-Accessory Continuity — Absolute

Established worn items stay same body location unless visibly moved. Partial occlusion okay; disappearance/duplication/side swap not.

## Orientation / Hinge / Handle / Track Continuity — Absolute

Reverse camera may flip the image but not the story-world mechanics.
Preserve:
- front-door hinge/handle/smart-lock side/opening arc
- cabinet hinge/handle/open direction
- building glass-door/elevator panel/track/hinge behavior
- binder spine/rings/page-turn side
- knife blade/handle/sheath-mouth orientation
- appliance front/back and cord-origin
- pot handle/cloth side
- chair front/back/pushed angle

If a view makes the correct mechanism awkward, change camera—not the mechanism.

## Object Scale / Fit Continuity — Absolute

World-space size is continuity.
Do not secretly resize objects to make a layout fit.
Examples:
- speaker/stockpot/lid/towels must fit actual cabinet volume
- emergency tray must fit flashlight/radio/sheathed knife at stable sizes
- A5 notebook must retain true A5-like footprint in table zone
- pot/chair/table/phone/tablet/key/candle/packets/TV retain stable scale
- characters remain consistent scale relative environment

Close-ups magnify on page only; they do not change story-world size.

## Depth-Order / Contact Continuity — Absolute

Flat overlap does not automatically prove physical relationship.

Layout must make real depth readable when it matters:
- fingers actually grip/wrap around object/wrist
- feet share floor plane with packet
- hips align seat for seated pose
- hand contacts mask hardware/door handle/cabinet handle
- blocking character occupies real floor-plan position between character and threat
- elevator entry crosses real threshold
- a foreground close-up cannot hide a silent world-space relocation

If contact/depth reads ambiguously, use a clearer camera.

## Flexible Object / Gravity / No-Clipping — Absolute

Cords, plugs, towels, cloth, straps, hair, paper, packets and falling objects obey support/gravity/collision.

Reject layouts where:
- loose plug floats
- cord passes through TV stand/wall/cabinet/counter/furniture/appliance
- cord length/slack changes to suit shot
- cloth/towel intersects solid speaker/pot/lid/cabinet volume
- falling knife/chopsticks/packet passes through body/table/chair
- phone/notebook/pen/lid hovers above support plane

Graphic simplification is fine; impossible topology is not.

## Prop Topology / Relative Placement — Absolute

Preserve physical relative positions, scale, orientation and depth—not just count.
Examples:
- pot same trivet/location/handle direction
- cloth same handle side
- candle same table point
- chopstick rest points
- packet/wrapper positions
- pushed chair angle
- knife floor point/orientation
- storage lid/towels/speaker/cord on same real support planes
- separate floor evidence remains separate
- notebook zone remains clear
- storage pot and noodle pot remain distinct locations/roles

## Same-Object Wide / Close-Up Semantics — Absolute

Close-up/inset is normally SAME physical object/person, not another copy.
Same-moment states must agree; action progression advances once. Use dividers/reading order so representational detail cannot be read as duplicate object/world-space body.

## Mandatory Mechanism Visibility — Absolute

Layout may not hide decisive mechanism for prettier reaction.
Show contact/source for plug/socket, key, blade/sheath, knife fall, chair sit/stand, cabinet handle/hinge, candle, bag/tablet, packet, pen/notebook, mask hardware, wrist grip/release, door/elevator threshold.

## Character ↔ Environment Interaction — Absolute

Every slice physically believable:
- real body support
- seated body actual chair
- reachable target
- truthful eyeline
- hinge/track motion
- collision-free route
- evidence obstacle clearance
- stable scale
- truthful depth order
- reverse angle derivable from floor plan

## Hand Occupancy / Support — Absolute

Account for two hands and real body/surface support. Close-up cannot imply ownership/support impossible in wide.

## Deterministic Body / Object Progression — Absolute

Show continuity-critical transition: crouch→stand, closed notebook→open, pocket→hand→pocket, object hand→surface→release, old foot mark→single step→new mark, held wrist→open fingers→air gap.

## Black Read-Slice Grammar — Absolute

Every distinct vertical slice gets small black gutter; side-by-side views use diagonal/slanted black divider. Suspense/time cuts may use slightly stronger compact gap. Never giant filler band. A/E technical seam remains invisible when art continues.

## Narration Placement / Scenario Integration — Absolute

Narration treatment/placement follows scenario, not one top-left box. Never cover action/evidence.

## Lettering / SFX Evidence Safety — Absolute

Never let text cover/sever contact, hinge/track, scale/fit, depth proof, plug/cord, key, knife, chair, mask/wrist, candle, food path, packet, phone/notebook placement, device clues.
Reflow text or camera instead.

## No Dead Bottom Canvas — Absolute

No huge empty black/white areas unless real story function. Never invent filler.

## Reader Background / Power State

Powered scenes neutral baseline. Outage deep charcoal/black field with readable separation and no invented light. Restore normal baseline after Unit power return.

## No Traditional / Technical Page Artifacts — Automatic Reject

No page numbers, V/P/strip/beat/panel/scene/shot IDs, temp-state labels, crop guides, QA notes, technical headers/footers.

## Text Safety

Never split reader-facing text across seams/dividers.
