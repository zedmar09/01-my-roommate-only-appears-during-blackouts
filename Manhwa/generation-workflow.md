# Manhwa Generation Workflow

## Production Authority

`Manhwa/` is the sole active visual-production pipeline.

Converted/audited Manhwa chapter files are self-contained production authority. `Source-Archives/` is reference-only material for chapters not yet converted and must never be generated directly as page-grid manga.

## Chapter 1 Plan

- 1 continuous reader-visible chapter
- 146 internal read beats
- 32 technical strips
- one fixed width across all generated strips

## Sequential Production

1. Read the current strip prompt and chapter manifest.
2. Attach required character canonical PNG(s).
3. Attach the smallest relevant approved environment canonical set.
4. Attach relevant approved core-object canonical(s) when visible/state-critical.
5. For Strip 002 onward, attach the immediately previous APPROVED strip.
6. Generate one tall vertical technical strip.
7. QA script, identity, movement, object routes, environment geometry, power state, lettering, SFX, supernatural signature, seam type, and lower-canvas use.
8. Reject/regenerate before proceeding if any mandatory item fails.
9. Only an APPROVED Strip N becomes temporary continuity authority for Strip N+1.
10. After the last strip passes, stitch in order, crop intentional overlaps, run seam QA, then uniformly resize for publishing.

## Reference Priority

Story/current strip > character identity > environment geometry > object identity/state vocabulary > previous strip temporary state.

If an approved previous strip conflicts with an approved environment/object canonical, do not propagate the drift.

## Power-State Lock

- Strips 014–025 contain the actual Unit 2407 outage sequence.
- Hyun-woo is physical only while Unit 2407 itself lacks ordinary supplied power.
- City power returning outside is not the disappearance trigger.
- Strip 025 restores Unit 2407 power; Hyun-woo is simply absent on the next readable beat.
- Strips 026–032 remain normally powered.

## No-Dead-Bottom Rule — Absolute

Reject any strip with a huge unused white/neutral/black tail that has no narrative function. Never invent filler captions/dialogue/SFX. Prefer existing composition, environment, action/reaction, atmosphere, reveal timing, or a compact seam buffer.

## Automatic Reject Rules

Reject for wrong/missing text, invented reader-facing text, wrong source ownership, identity drift, environment/object redesign, teleporting movement/props, wrong current power state, physical Hyun-woo while powered, missing Hyun-woo during physical blackout scenes, visible page-grid artifacts, obvious seams, double blank seams, wrong helpful/hostile signature, or glossy/photoreal/3D rendering.
