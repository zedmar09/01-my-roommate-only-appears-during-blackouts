# Manhwa Vertical-Scroll Workspace

`Manhwa/` is the sole active visual-production pipeline for `My Roommate Only Appears During Blackouts`.

The former `Comics/` manga/page-production directory has been retired. New chapters, revisions, environment references, object references, and generated story strips belong under `Manhwa/`.

## Authority — Absolute

For active production, authority is:
1. current chapter/strip script
2. character canonicals
3. environment canonicals
4. core-object canonicals
5. immediately previous approved strip for temporary state/seam continuity

`Manhwa/Source-Archives/` may preserve not-yet-converted legacy story/script material, but it is never a generation target and never overrides a converted/audited Manhwa chapter.

## Current Chapter 1 Lock

- one continuous vertical chapter
- 146 internal read beats (`V01–V146`)
- 32 technical strips (`strip-001–strip-032`)
- no reader-visible page/strip/beat numbering
- ending: powered Unit 2407 + unplugged TV displaying `NEW TENANT CONFIRMED`

## New Chapter / New Environment Rule

Before production of every new Manhwa chapter:
- inventory environments
- reuse approved canonical packs where possible
- create/approve new canonical packs for new recurring locations
- identify recurring plot-critical objects and create/reuse object canonicals
- build the continuous-scroll beat plan and strip manifest

## No-Dead-Space Rule — Absolute

Large vertical space must perform a story function: existing narration/time transition, meaningful silence, suspense/reveal delay, scripted sound-first beat, reaction hold, atmosphere/environment continuation, or controlled seam.

Never invent filler narration/dialogue/SFX merely to occupy canvas. Expand the existing composition, canonical environment, reaction, darkness/rain/effect field, or use only a compact seam buffer.
