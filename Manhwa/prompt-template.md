# Technical Strip Prompt Template

Use this structure for every active Manhwa production strip.

```text
Create exactly ONE tall full-color 2D manhwa TECHNICAL STRIP belonging to the same continuous chapter scroll.

CONTINUOUS-CHAPTER LOCK
This is not a page, episode, or reader-visible part.

PRODUCTION AUTHORITY
Use current chapter beat plan/manifest + this strip's exact locked reader-facing script. Binding global style/SFX/seam/layout/workflow/readiness + adopted hardening addenda always apply. Current strip may be stricter, never looser.

INTERNAL READ BEATS — PRODUCTION ONLY
V##–V## planning IDs only. Never render V/P/strip/beat/scene/panel/shot/QA/temporary-state metadata anywhere, especially top-left.

ATTACH — REQUIRED
List EVERY exact required visual reference:
- character canonical path(s)
- environment canonical path(s)
- object canonical path(s)
- previous approved strip for 002 onward
- current prompt
Do not infer attachments from another file.

REFERENCE AVAILABILITY — BLOCKING
Missing/stale/wrong-path/unapproved canonical → STOP. Never substitute improvised/rejected reference or Markdown prompt as visual canonical.

ATTACHED-REFERENCE OBEDIENCE — ABSOLUTE
Approved WebPs are binding permanent identity/geometry/object authority, not inspiration. Recompose shot; never redesign canon.

PREVIOUS-STRIP LIMIT — ABSOLUTE
Previous approved strip controls temporary story state only. It never overrides permanent canon.

DERIVED MICRO-DETAIL — CANON-SUBORDINATE
If a required practical detail is not clear in attached canon, exhaust existing refs first, derive only the smallest necessary detail inside existing canonical geometry, never add/move architecture, and keep it temporary chapter continuity only.

REFERENCE PRIORITY
Current user instruction > story/current strip > approved character > approved environment > approved object > current hardened prompt > previous approved strip temporary state > canon-compatible derived micro-detail.

LEGAL TIME / LOCATION CUT — ABSOLUTE
State what a cut may change and what evidence/identity persists. A legal cut may establish a new temporary pose or clothing-layer state, but never resets permanent canon/evidence.

START STATE — ABSOLUTE
List exact character pose/facing/feet/hands, emotional intensity, gesture, relative character scale, clothing-layer state, worn accessories + side, body/wardrobe identity, object locations/counts/orientation/scale, food/props, cords/plugs/sockets, doors/cabinets, chairs/support, power/light/device state and previous seam state.

ALLOWED CHANGES — ABSOLUTE
List only physical/performance changes allowed. Anything not listed stays unchanged.

DETERMINISTIC SINGLE-MECHANISM — ABSOLUTE
Choose ONE physically authoritative solution for each continuity-critical action.

END STATE — ABSOLUTE
List exact physical + performance state carried to next strip.

WHOLE-BODY ANATOMICAL TOPOLOGY — ABSOLUTE
Every character is one physically coherent human body. Reject extra/missing/duplicated limbs/body parts, detached hands/feet/ears/hair masses, impossible joints, impossible shoulder/arm or pelvis/leg connection, or close-up limb incompatible with adjacent wide-shot body. Partial occlusion is allowed only when hidden connections remain physically possible.

LIMB OWNERSHIP / ANATOMICAL SIDE — ABSOLUTE
A close-up hand/wrist/foot/arm/leg belongs to the SAME character and SAME physical side established by adjacent views. Preserve sleeve/glove/tattoo/scrunchie/body cues when ownership matters. Reverse shot may flip screen side; anatomical ownership may not.

PERMANENT CHARACTER LANDMARKS — ABSOLUTE
List character-specific permanent side/pattern locks when relevant.
Examples:
- Nari: exactly one beauty mark beside anatomical LEFT corner of mouth
- Hyun-woo: same tattoo-map side/pattern relationships, technical mask construction and low-tied hair
- Mrs. Na: same jade earrings, watch wrist, dark gloves
- Seungjae: same watch wrist, earbud ears and medium-brown hair part/silhouette
Never mirror a permanent landmark because the camera reverses.

FACE / AGE / BUILD / HAIR IDENTITY — ABSOLUTE
Close-ups/expressions/lighting may not recast the character. Preserve canonical face proportions, age, hair length/part/tie/fringe, height/build and permanent marks/accessories.

POSE-STATE CONSERVATION — ABSOLUTE
A camera cut is not a pose reset.
Track standing/seated/crouched/kneeling/walking/leaning/shielding state, weight-bearing legs, shoulders/hips/torso facing, head orientation, elbow/arm/hand gesture, spine lean, feet and center of mass.
If only head/eyes turn, shoulders/hips/feet remain. A new full-body turn, stance or gesture must be visibly staged or occur at a legal cut.

BODY-FACING / SHOULDER-HIP AXIS — ABSOLUTE
Stationary dialogue/action preserves story-world shoulder/sternum/hip/foot direction. Reverse shots may flip the page but not silently rotate the body. Head rotation may differ within believable neck range only. If a turn needs re-planted feet/chair support, show it.

RELATIVE HEIGHT / BUILD — ABSOLUTE
Preserve canon-compatible world-space relationships on the same floor plane. Perspective changes apparent screen size only. Do not resize one character for romance, intimidation, comedy or dramatic framing.

EXPRESSION / EMOTION CONTINUITY — ABSOLUTE
Carry emotional intensity through adjacent slices/seams unless the story creates a real cause for change. Avoid random smile/panic/anger/blank resets, unscripted tears/screams/chibi shock/villain smirks/romantic glamour. Use grounded adult performance matching the event.

GESTURE CONTINUITY — ABSOLUTE
Pointing, shielding, phone hold, hand-to-ear, knife-low, object-contact, notebook/pen and similar gestures remain until visibly changed/released. Never invent a gesture that conflicts with occupied hands or fixed props.

CLOTHING-LAYER / CLOSURE STATE — ABSOLUTE
Within one continuous scene preserve jacket/coat present/absent, open/closed state where visible, hood up/down, sleeve state, bag worn/removed, headphones position, mask seated/lowered state. Reverse shots cannot silently alter them.

HAIR / GARMENT MOTION — ABSOLUTE
Flexible motion may sway hair/clothing naturally but cannot redesign length/part/tie/volume or garment construction. Motion cannot hide an unperformed body turn.

WARDROBE / LOCAL-COLOR / MATERIAL IDENTITY — ABSOLUTE
Within one continuous scene preserve clothing construction, signature colors and matte material identity unless a scripted/legal wardrobe change says otherwise. Lighting can change value, not identity hue/material.

CLOTHING / BODY OCCLUSION TOPOLOGY — ABSOLUTE
Sleeves/trousers/coats/hoodies/hair/headphones/bag/mask straps must attach to the correct continuous body. Clothing cannot create/hide an extra or missing limb. Tattoos cannot show through opaque clothing.

SPEAKING / LISTENING / MOUTH-STATE LOGIC — ABSOLUTE
Visible acting must agree with line ownership. Listener does not mouth speaker's line. Narration/internal thought/device/speaker audio is not human spoken dialogue. Masked Hyun-woo does not expose/redraw lower face to show speech.

MICRO-CONTINUITY — ABSOLUTE
Visible story state persists slice X→X+1 unless visible/legal change occurs. Occlusion is not disappearance.
Track hands, feet, pose/facing, emotion/gesture, relative character scale, clothing-layer state, body topology, facial landmarks, hair/wardrobe, worn accessories, food/noodles, pots/chopsticks/packets, cords/plugs/sockets, key/manual/note/pen/notebook, phone/tablet/bag/pockets, knife/sheath, candle, chair, cabinet/stockpot/lid/towels/speaker, distance/depth/power/device state.

TEMPORARY ANATOMICAL-SIDE IDENTITY — WHEN APPLICABLE
Use production-only identities such as KNIFE HAND / PHONE HAND / WRITING HAND / SCRUNCHIE WRIST / STEP FOOT / CANDLE FOOT / BAG SHOULDER / UMBRELLA HAND / PHONE POCKET where reverse-shot drift could break continuity. Never render labels.

WORN-ACCESSORY PERSISTENCE — ABSOLUTE
Established worn items remain same body location unless visibly moved. Partial occlusion okay; disappearance/side swap/duplication/clipping is not.

ORIENTATION / HINGE / HANDLE CONSERVATION — ABSOLUTE
Preserve door/cabinet/elevator mechanics, object front/back, appliance cord origin, binder spine/page-turn, knife/sheath axis, pot handle/cloth side, chair orientation.

OBJECT SCALE / FIT CONSERVATION — ABSOLUTE
Recurring objects retain stable world-space size. Containers/surfaces must physically fit contents without resizing.

DEPTH / CONTACT — ABSOLUTE
2D overlap is not contact. Show real grips, foot/floor contact, seated support, mask hardware, wrist grip and blocking depth.

FLEXIBLE OBJECT / GRAVITY / NO-CLIPPING — ABSOLUTE
Cords/plugs/towels/cloth/hair/straps/packets/paper/clothing obey support/gravity/collision.

CAMERA AXIS / EYELINE — ABSOLUTE
Continuous conversation/action preserves world-space sides and gaze targets. Crossing 180° axis requires neutral reorientation.

PERSPECTIVE / LENS INTEGRITY — ABSOLUTE
Use ordinary manhwa perspective; no fisheye/ultra-wide/forced-perspective warping of canon/body/object proportions.

MOBILE-SCALE EVIDENCE LEGIBILITY — ABSOLUTE
Continuity-critical proof must be understandable at normal mobile size. Use adjacent SAME-OBJECT detail when needed rather than resizing story-world objects.

CROP / GUTTER / DIVIDER SAFE MARGIN — ABSOLUTE
Keep decisive contact and enough context inside frame; never let crop/gutter/divider/seam amputate proof.

PHYSICAL TEXT-PLANE / READABILITY — ABSOLUTE
Device text stays on actual screen; binder/note/notebook text stays on actual page. Exact story text must remain readable at mobile size.

LIGHTING SOURCE / SHADOW DIRECTION — ABSOLUTE
Within unchanged light state, keep physically coherent source/shadow direction. Screens are not room lights unless scripted.

REFLECTION / SHADOW FALSE-DUPLICATE BAN — ABSOLUTE
No un-scripted reflected/shadow duplicate people/objects or human silhouettes.

GRIP / FINGER ERGONOMICS — ABSOLUTE
Critical grips use safe usable surfaces. Fingers cannot fuse/pass through handled objects. A close-up hand must still belong to the correct body.

AUDIO SOURCE / REACTION DIRECTION — ABSOLUTE
Offscreen/device audio remains at real story source; SFX/voice placement and character reaction point to it.

TOP-TO-BOTTOM READER ORDER — ABSOLUTE
Action, dialogue, narration, device text and SFX read in exact scripted causal order. Use more vertical space if necessary; do not rewrite dialogue.

CRITICAL OBJECT / LIMB OWNERSHIP — ABSOLUTE
Close-ups retain enough connected context to prove hand↔arm/body, foot↔leg/body, plug↔cord/appliance, knife↔same knife, notebook page↔same notebook.

PROP TOPOLOGY / RELATIVE PLACEMENT — WHEN APPLICABLE
List physical relationships that cannot swap across reverse shots.

REAL-SCENARIO CAUSALITY — ABSOLUTE
`START STATE → CAUSE → VISIBLE PHYSICAL ACTION → RESULT → PERSISTENT END STATE`.

MANDATORY ACTION-PROOF FRAMING — ABSOLUTE
Show decisive contact or immediately adjacent causal detail. SFX/result cannot replace physical mechanism.

SAME-OBJECT REPRESENTATION / INSERT — ABSOLUTE
Close-up/inset does not create another physical copy. Same-moment views agree; state advances once.

CHARACTER ↔ ENVIRONMENT REALITY — ABSOLUTE
Verify body support, chair alignment, reachability, eyeline, hinge/track motion, routes, collision clearance, scale, depth and truthful reverse angles.

WALL-SOCKET RULE — WHEN APPLICABLE
`unplug` = plug BODY removed from WALL-MOUNTED outlet; appliance-side cord remains attached. Proof includes enough wall context and same continuous cord; loose plug obeys gravity/no-clipping.

LETTERING / BALLOON / SFX EVIDENCE SAFETY — ABSOLUTE
Reader-facing text cannot cover proof, character identity/pose landmarks or reorder causal events.

STRICT FLAT 2D HUMAN-DRAWN STYLE — ABSOLUTE
Strict flat 2D human-drawn Korean manhwa/webtoon. Clean line art, flat colors, restrained hard-edged cel shading, matte materials, stable anatomy and mobile readability. No photoreal/3D/glossy/cinematic/painterly/airbrushed/over-rendered output.

NARRATION DESIGN BY SCENARIO — ABSOLUTE
Keep wording exact; treatment/placement follows beat function, not one repeated top-left box. Narration is not mouthed as dialogue.

SEAM IN
State exact continuing anchors, including pose/facing/emotional intensity/relative scale/clothing-layer state when applicable.

BLACK READ-SLICE DIVIDER — ABSOLUTE
Every distinct vertical slice gets small black gutter; side-by-side views use diagonal/slanted divider. Nothing important crosses slash. No giant filler band.

VERTICAL COMPOSITION
Continuous manhwa composition, not page grid. Every camera change physically possible and mobile-safe.

SCRIPT / SOURCE OWNERSHIP LOCK
List exact reader-facing lines/SFX/device/note text and source. Device text stays device; thought/narration does not become speech.

SFX PHYSICAL CHAIN — ABSOLUTE
SOURCE → ACTION → EXACT SOUND → TIMING → PLACEMENT → STATE CHANGE → NEXT CONSEQUENCE.

NO DEAD BOTTOM — ABSOLUTE
No giant unused tail or invented filler.

SEAM OUT
Define exact next-strip physical + performance state.

AUTOMATIC REJECT IF
- wrong/missing/unapproved attachment
- canonical redesign or previous-strip drift overrides canon
- illegal time-cut reset
- contradictory physical alternatives
- teleporting movement/object transfer
- adjacent state disappears
- pose/body-facing silently resets at camera cut
- relative character height/build changes without physical/perspective cause
- emotional intensity resets/jumps without story cause
- gesture changes/disappears without visible release/change
- clothing-layer/hood/sleeve/bag/mask state changes without action/legal cut
- hair/garment motion becomes a redesign
- strip seam forgets inherited pose/facing/emotional state
- extra/missing/duplicated limb/body part or impossible joint/body connection
- close-up limb belongs to wrong character/side or cannot connect to adjacent body
- permanent face mark/tattoo/accessory landmark mirrors/migrates/disappears
- face/age/build/hair identity recasts under close-up/expression/light
- wardrobe/local color/material changes without valid cause
- clothing/accessory occlusion hides impossible anatomy
- listener mouths another speaker's line or thought/device/audio is acted as human speech
- same-object insert creates duplicate/incompatible state
- temporary anatomical side silently swaps
- worn accessory disappears/swaps/clips/floats
- hinge/handle/spine/track flips
- recurring object scale changes or fit is faked
- contact is fake overlap
- depth order contradicts floor plan
- flexible object clips/floats
- camera axis/eyeline wrong
- lens distortion warps canon
- proof microscopic/crop-divided
- light/shadow source changes without cause
- reader order contradicts script
- in-world text unreadable/floating
- reflected/shadow duplicate appears
- impossible grip
- offscreen audio wrong source
- prop topology swaps
- impossible route/support/collision
- lettering hides evidence/identity/pose
- appliance-side cable removed instead of wall plug
- silent re-plug
- any production/temp-state label appears
- narration generic/repetitive top-left
- unsupported SFX
- missing divider
- giant dead canvas
- visible technical seam
- strict flat 2D violation
```

After any correction, re-audit corrected strip and adjacent seams. After final strip, run a fresh clean-room visual audit of the stitched chapter rather than inheriting previous PASS labels.
