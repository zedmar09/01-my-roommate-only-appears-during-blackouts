# Building Shared-Area Canonical Pack

Locks the residential entrance/canopy, glass doors, ground-floor lobby, and elevator-bank geography for every chapter that returns to Nari's building.

This pack is permanent and reusable. Do not create chapter-numbered duplicates.

## Reference Synthesis Rule

Generate/revise these from the strongest approved building/lobby artwork plus the locked geography. Do not replace the accepted residential building with an unrelated hotel, office, or mall interior.

## Approved Repository WebP Authorities

Use these exact files in production attachment lists:
- `building-lobby-elevator-reference.webp`
- `rainy-building-entrance-reference.webp`

The directional rule remains absolute: after entering, the glass entrance stays behind the characters and the elevator bank remains deeper inside. Reverse shots may change screen direction but must remain physically truthful to the same canonical layout.

The image prompts may continue to generate PNG first locally. After approval, manually convert to the exact WebP names above for GitHub storage/production use.

`building-shared-areas-bible.md` is the written route/geography authority. `building-shared-areas-bible.webp` is not a required Chapter 1 strip attachment and must not override the two approved environment references above.
