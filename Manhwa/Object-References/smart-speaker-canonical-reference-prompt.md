# Smart Speaker — Canonical Object Reference Prompt

Generate one production object-reference sheet for the SAME recurring smart speaker used across the series. No characters.

Show consistent front/side/back/top views plus state variants.

## Body / Cord Authority — Absolute

- small screenless matte-charcoal corded cylinder
- ordinary household scale
- SAME one power cord remains attached to speaker body across all normal/unplugged/storage states
- SAME wall-end electrical plug remains attached to that cord
- subtle indicator hardware
- no brand/logo/text printed on body

When showing normal power context, the wall-end plug goes into an ordinary WALL-MOUNTED electrical socket/outlet.

When showing `unplugged`:
- appliance-side cord remains attached to speaker body
- SAME wall-end plug is physically OUT of the wall socket
- wall socket is empty if shown
- loose plug remains attached to SAME cord
- do NOT depict an empty speaker-side power port as the unplug proof

## State Variants

A. NEUTRAL POWERED
Speaker body + attached cord + wall-end plug connected to wall power where context is shown.

B. ORDINARY ASSISTANT ACTIVATION
Restrained `BLIP` indicator behavior. Same hardware.

C. CLEAN HELPFUL / HYUN-WOO COMMUNICATION
Weak stable cyan-white hardware accent, no hostile black pixels. Same hardware.

D. UNPLUGGED FROM WALL — PROOF STATE
Speaker-side cord remains attached. Loose wall-end plug visible outside wall socket. No missing cord, no detached speaker-side cable.

E. STORED IN CANONICAL STOCKPOT
SAME unplugged speaker inside SAME household storage stockpot under EXACTLY TWO dish towels. SAME attached cord + loose wall plug must remain physically accounted for and may be naturally coiled/laid with the speaker. Do not delete the cord/plug because it is under towels. Include SAME lid as part of the storage setup.

F. UNPLUGGED BORROWED-CURRENT VOICE STATE
Same stored/unplugged physical configuration, still NO wall connection. Tiny contained indicator only, no room glow. Supernatural borrowed current does not physically reconnect the plug.

The stockpot in this reference is the recurring speaker-storage pot near the refrigerator cabinet zone and is NOT the later dining noodle cooking pot.
