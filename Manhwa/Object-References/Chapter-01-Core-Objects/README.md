## Reference Synthesis Rule

Use the best already-approved strips where each object is clearly visible as reference input, plus source object locks. The purpose is to freeze the accepted object identity, not redesign it.

Recommended visual evidence:
- speaker: strongest approved appearances from move-in / first voice / cabinet reveal
- TV: strongest approved neutral/unplugged/helpful appearances; hostile final state follows the state prompt
- refrigerator: strongest approved neutral body/display appearances; hostile states follow the state prompt

If existing approved strips disagree, preserve explicit source locks and the user's preferred/strongest approved object geometry. Once approved, the object sheet becomes authority for future/re-generated strips.

Sample display text in the prompt files demonstrates effect styling only; actual strips always use their own locked script.
