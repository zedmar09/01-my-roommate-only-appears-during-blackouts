# Core Object Bible

These object identities are reusable across every chapter in which the SAME physical object returns.

## Universal Object-State Rule — Absolute

A recurring object is one continuous physical object across adjacent visual slices and strips. Camera changes do not authorize redesign, disappearance, duplicate copies, changed cord routing, changed state, or changed location.

Every state change follows:
`OLD STATE → PHYSICAL ACTION → NEW STATE → PERSISTENCE UNTIL NEXT VISIBLE CHANGE`.

## Wall-Socket Meaning of `Unplugged` — Absolute

Unless a future script explicitly establishes a detachable appliance-side cable action, `unplugged` means **the electrical plug has been removed from a WALL-MOUNTED socket/outlet**.

For corded objects:
- appliance-side cord remains attached to object body
- SAME cord ends in SAME electrical plug
- plug is removed from wall socket
- plug remains attached to cord
- wall socket is empty
- unplugged state persists until an explicit re-plug action

Do NOT treat an empty appliance power port or cable detached from appliance body as equivalent to being unplugged from the wall.

## Food / Dining Continuity Around Core Objects

When a recurring-object scene includes food, pot, bowl, chopsticks, packet/wrapper, candle, chair, cabinet, or other scene-state evidence, those items persist across adjacent slices even if they are not core object canonicals. Food/noodle amount may change only through a visible bite/slurp/placement/spill or valid time cut. Close-ups and dialogue do not erase props.
