# Core Object Bible

These object identities are reusable across every chapter in which the SAME physical object returns.

## Smart Speaker

Same exact object throughout:
- small screenless matte-charcoal corded cylinder
- ordinary residential scale
- one visible power cord / plug
- subtle hardware indicator only
- no brand/logo

States:
- neutral powered
- ordinary assistant `BLIP`
- clean helpful/Hyun-woo communication
- hidden under two towels inside storage stockpot
- unplugged but borrowing just enough current for voice

Spoken dialogue remains AUDIO. Never print Hyun-woo's spoken words on the speaker body.

## TV

Same exact matte-black flat TV throughout Unit 2407:
- fixed screen proportions/bezel/stand
- stable power-cord/outlet relationship
- visibly unplugged when story says unplugged
- nonreflective

States:
1. neutral OFF
2. clean helpful/Hyun-woo text — stable cyan-white, minimal/no hostile corruption
3. hostile activation — `KZZT`, full-screen signal takeover, broad horizontal sync tear/scanline disruption, broken/doubled stark-white text, black-pixel interference at screen edges
4. hostile message while Unit 2407 remains powered when scripted

Representative style samples only:
- `YOUR PATCH NOTES ARE TOO LONG.`
- `DON'T LOOK AT THE FRIDGE.`
- `NEW TENANT CONFIRMED`

## Refrigerator

Same exact matte cool-gray Unit 2407 refrigerator throughout:
- two upper doors
- lower freezer drawer
- recessed handles
- narrow upper-right built-in display
- nonreflective body/display

Hostile state remains CONTAINED to the narrow display and behaves like embedded diagnostics/identity locking:
- segmented typing/progression
- doubled broken stark-white glyphs
- black pixels crawling from display seams/edges
- contained corrupt UI feeling
- no full-door TV takeover

Representative style samples:
- `TENANT PROFILE: PENDING`
- `YOON NARI`
- `IDENTITY LOCKING`

## Shared Hostile Family / Different Manifestation

TV and refrigerator share the hostile broken-white + black-pixel family, but must never look identical:
- TV = broad broadcast/signal takeover of a full screen
- refrigerator = narrow embedded diagnostic/locking intrusion

Effects stay contained; no room-flooding neon/glow.
