# TV — Canonical Object + State Reference Prompt

Generate one production reference sheet for the SAME recurring matte-black TV in Unit 2407. No characters.

This object sheet must make the TV's real electrical connection physically unambiguous so later story strips cannot interpret `unplugged` as disconnecting a cable from the television body.

## Body / Cord / Wall-Socket Authority — Absolute

BODY TURNAROUND:
- front, three-quarter, side/back views
- fixed screen proportions, bezel, stand/base
- SAME single power cord permanently attached to the TV body in every state unless future canon explicitly changes hardware
- SAME wall-end electrical plug attached to that cord
- show the canonical WALL-MOUNTED electrical socket/outlet as the normal power destination
- matte nonreflective screen/body; no brands/logos

### Plugged state
Show SAME TV power cord connected to TV body and SAME wall-end plug physically inserted into a WALL-MOUNTED electrical socket.

### Unplugged state — NON-NEGOTIABLE
`UNPLUGGED` means:
- TV-side cord remains attached to SAME TV body
- SAME cord runs to SAME loose wall-end electrical plug
- wall-end plug is physically OUT of the WALL-MOUNTED socket
- wall socket is visibly EMPTY
- plug remains attached to cord; plug does not disappear
- socket remains on wall; never move it to TV stand/furniture/floor

ABSOLUTELY DO NOT depict unplugging as:
- cable removed from TV body
- empty power port on back/side of TV
- severed/detachable appliance-side cable
- loose cable end at TV body
- missing plug
- hidden second power cable

The recurring supernatural proof in Chapter 1 depends on this exact visual logic: **TV can remain active while the electrical plug is physically outside the empty wall socket.**
