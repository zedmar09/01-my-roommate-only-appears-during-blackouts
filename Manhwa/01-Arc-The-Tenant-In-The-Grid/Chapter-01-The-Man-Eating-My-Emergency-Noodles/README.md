Source story:
`Comics/01-Arc-The-Tenant-In-The-Grid/Chapter-01-The-Man-Eating-My-Emergency-Noodles/`

This directory is the test conversion of Arc 1, Chapter 1 from fixed comic pages into a continuous vertical-scroll manhwa.

## Canon Authority

The existing Chapter 1 `Comics/` files remain authority for:
- story events
- exact supernatural rules
- character knowledge
- dialogue meaning
- apartment geography
- prop continuity
- device signatures
- object handoffs

This directory changes **presentation**, not canon.

## Manhwa Adaptation Goal

The Chapter 1 test should feel less like eighteen separate comic pages and more like one long phone-scroll episode.

Primary changes:
- remove panel-order markers
- break the 18-page grid rhythm into scroll sequences
- use variable vertical gutters for pacing
- give important reveals more image height
- use full-width establishing/reveal panels
- integrate SFX into artwork
- use clean mobile-readable balloons
- allow black/charcoal page background during blackout sequence
- use a richer modern 2D manhwa finish while preserving canonical identities
