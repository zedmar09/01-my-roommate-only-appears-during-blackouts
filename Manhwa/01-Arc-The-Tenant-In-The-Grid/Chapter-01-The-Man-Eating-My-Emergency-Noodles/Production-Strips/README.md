# Production Strips — Technical Only

Files in this folder are **not reader-visible pages or scroll episodes**.

They are same-width technical generation chunks used to build one continuous Chapter 1 master.

Rules:
- every strip is 1080 px working width
- strip height may vary
- never add strip/page labels inside artwork
- use previous APPROVED strip as continuity reference when direct
- allow a small continuity overlap if useful, then crop it during assembly
- strip boundaries must fall inside safe gutters
- no repeated chapter title/header/footer
- no page-number/circled-panel-number treatment
- stitch all approved strips before judging final pacing

Pilot strips 001–003 cover the top portion of the same Chapter 1 scroll. They must be assembled immediately for review.
